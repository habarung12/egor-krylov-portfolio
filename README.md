# Портфолио Egor Krylov

Статический сайт: `index.html` + `styles.css` + `app.js`. Сборка не нужна.

## Как открыть
Двойной клик по `index.html` или локальный сервер:

    py -m http.server 5173

## Что где править
- **Цвета и шрифты** — блок `:root` в начале `styles.css` (`--acid` — лайм-акцент).
- **Контакты (Telegram, почта)** — `CONFIG.contacts` в начале `app.js`. Пустые ссылки на сайте не показываются.
- **Названия и описания проектов, цвета-свотчи** — массив `PROJECTS` в `app.js`.
- **Слайды первого экрана** — `CONFIG.hero` в `app.js`.
- **Тексты (о себе, услуги)** — `index.html`.

## Картинки
`assets/works/<проект>/NN.webp` (до 2000 px) и `NN_t.webp` (превью 900 px),
сделаны из PNG/PSD в `D:\GNCOW\PSD`. Исходники не изменялись.
Список работ — `assets/works.js` (поле `file` — имя исходного файла).

## Публикация
Подходит любой статический хостинг: GitHub Pages, Netlify, Vercel — загрузить папку целиком.
